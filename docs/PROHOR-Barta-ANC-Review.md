# PROHOR Barta | ANC terminology source record

Status: **project-selected reference for basic terminology**. Source checked 16 November 2026. Publisher: World Health Organization. Edition: WHO/RHR/16.12, 25 November 2016. Use the Overview of the [WHO executive summary](https://www.who.int/publications/i/item/WHO-RHR-16.12).

| Language | Independently worded definition |
|---|---|
| English | ANC stands for antenatal care. It means health care during pregnancy. |
| Bangla | ANC-এর পূর্ণরূপ antenatal care। এর অর্থ গর্ভাবস্থায় নেওয়া স্বাস্থ্যসেবা। |

Scope: basic terminology only. This project source check covers the definition and its attribution. The record does not represent clinical sign-off or permission to redistribute the WHO publication. The app serves independently written wording and links to WHO.

The catalog records the source version, section, check timestamp and basis separately from account-backed approvals. Verify both answer languages and the real source link on `/ask`.
